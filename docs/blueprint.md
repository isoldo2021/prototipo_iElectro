# **App Name**: ElectroSmart

## Core Features:

- Product Visualization: Display appliances with detailed images and specifications.
- Product Comparison: Compare technical specifications of different appliances side-by-side.
- Shopping Cart: Allow users to add products to a shopping cart.
- Checkout Process: Enable users to finalize their purchase, selecting the payment method.
- Warranty Addition: Option to add warranties to the purchased products before completing the payment.
- Installation Service: Allow users to add installation services to their purchase before checkout.

## Style Guidelines:

- Primary color: A vibrant blue (#4285F4) to convey trust and reliability, in line with the user's color preference.
- Background color: A very light blue (#F0F4FF) that provides a clean, accessible backdrop suitable for daltonics, offering sufficient contrast while maintaining a calming visual experience.
- Accent color: A deeper analogous blue (#3367D6), offering contrast and drawing user attention to key interactive elements without straining visibility for users with color vision deficiencies.
- Font pairing: 'Poppins' (sans-serif) for headlines, offering a modern, accessible look; and 'PT Sans' (sans-serif) for body text, ensuring readability and a contemporary feel.
- Responsive design to ensure optimal viewing experience across various devices (desktop, tablet, mobile).
- Use a consistent set of easily recognizable icons for product features and navigation, optimized for clarity and accessibility for users with color vision deficiencies.
